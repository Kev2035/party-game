# Foto del Memory

Metti qui le foto degli amici (`.webp`, `.jpg`, `.jpeg`, `.png`): una faccia per file, meglio se **piccole** (circa 250 px, sotto i 30 KB).

- **Nessuna foto**: il Memory usa le emoji.
- **Da 1 a 5 foto**: le carte mancanti sono emoji.
- **6 o più foto**: solo foto, scelte a caso a ogni partita.

Le stesse foto scendono anche sullo sfondo della sala d'attesa in TV.

Le foto in questa cartella sono ignorate da git, così non finiscono per sbaglio su GitHub. Vengono comunque incluse nel sito da `npm run dev`, `npm run build` e `npm run deploy`.
